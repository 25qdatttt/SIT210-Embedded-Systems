# Task 5.2C - Change the Light Intensity Using GUI

In this project, Python and Tkinter are used to create a graphical user interface (GUI) on a Raspberry Pi 4 to use Pulse Width Modulation (PWM) to adjust the brightness of an LED. The system is a continuation of the functionality of Task 5.1, where in addition to being able to change the room the user is able to turn the light intensity of the living room LED up or down with a slider, resembling a more sophisticated smart home lighting system.

In order to make the program organized, the code is broken down into multiple parts that are functional. The GPIO configuration also initializes all the LED pins and makes them ready to make outputs. The PWM is applied only to the living room LED, allowing the brightness to be controlled smoothly rather than on/off. The control led()-functions control the room selection, enabling the selected LED and disabling the rest, but the PWM is also used to control the brightness of the living room LED. The update brightness() method modulates the duty cycle of the PWM signal as the slider input varies and has a direct proportional effect on the LED brightness and updates the display label of the same. The exitapp() procedure will provide a safe shutdown by disabling all LEDs and clean up the GPIO resources.
