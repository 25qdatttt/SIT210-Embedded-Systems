# Task 2.1 

In this project, one can see a basic implementation of an embedded system that collects information from the environment and delivers it to the internet using a cloud platform. The system involves a combination of an Arduino Nano 33 IoT board and a temperature sensor (DHT22) and a light sensor (BH1750). The Arduino is used to read the temperature and light level from the sensors and send the information to a ThingSpeak channel using a WiFi connection to allow it to be monitored remotely.

The program is written in a modular programming approach in which the program code is broken up into several small functions. The startSensors() function is used to initialize the DHT22 and BH1750 sensors, and the connectWifi() function is used to connect the board to the WiFi network. In the loop() function the Arduino is reading the temperature and light values continuously. The show() function shows the sensor readings at the Serial Monitor and upload() function is used to send the data to the ThingSpeak platform. This project demonstrates how embedded systems can be utilized with web services in remote monitoring applications such as smart houses or environmental sensing systems.
