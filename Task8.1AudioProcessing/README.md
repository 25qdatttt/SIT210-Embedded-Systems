# Task 8.1HD Audio Processing

In this project, Python speech recognition, Bluetooth Low Energy communication, and Arduino Nano 33 IoT are used to create a voice-activated smart lighting system. The system includes LEDs representing the bathroom light, hallway light, and exhaust fan, along with a BH1750 digital light sensor for ambient light detection.

The Raspberry Pi captures voice commands through a USB microphone and converts speech into text using Python. The recognized command is then sent wirelessly through Bluetooth to the Arduino Nano 33 IoT, which controls the LEDs based on the current light level detected by the BH1750 sensor. The project demonstrates the integration of audio processing, wireless communication, and embedded system automation in a smart home environment.
